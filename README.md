# 照片圣诞树

在原版 3D 照片树上做性能优化：照片沿整个圆锥树身分布、随树旋转，支持散开和聚合。保留深色全屏场景、绿色树体、彩灯、金色立体星和飘雪。

本分支已撤回先前的 Canvas 2D / 贺卡式改版。主场景继续使用 Three.js 和 React Three Fiber；界面只有底部的散开／聚合、暂停旋转、相册和分享。摄像头手势识别已移除，鼠标与触摸均可直接操作。

## 本地运行

需要 Node.js 20.19 或更新版本。

```bash
npm ci
npm run dev
```

运行与构建前会自动生成照片缩略图和清单：

```bash
npm run photos
npm run lint
npm test
npm run build
npm run preview
```

## 替换照片

把照片放进 `public/photos/`，支持 JPG、JPEG、PNG、WebP、AVIF。文件名不用连续编号，照片数量也不用预先确定。默认把 `top.*` 排在前面，其余按自然文件名排序。

例如：

```text
public/photos/
  top.jpg
  1.jpg
  2.jpg
  海边.png
```

不再使用的源照片可以在这个目录中替换或移走；原始文件不会被转换脚本覆盖。生成结果写入 `public/generated/`，该目录不提交到源码仓库。

如需自己指定顺序、说明和替代文本，可选地创建 `public/photos/manifest.json`：

```json
{
  "photos": [
    {"file": "top.jpg", "alt": "第一张照片"},
    {"file": "海边.png", "caption": "想写的说明", "alt": "海边合照"},
    "2.jpg"
  ]
}
```

清单只选择列出的照片；没有清单时自动发现目录内照片。删除或替换有清单引用的文件时，也要更新清单。显式的 `{"photos":[]}` 表示空相册。0 张时仍保留树叶、灯饰和树顶星。

每张照片会生成：

- 最长边 320 px 的 WebP 缩略图，给树的纹理图集与相册缩略图使用。
- 最长边 1600 px 的 WebP 显示图，打开相册才加载。
- 自动修正 EXIF 方向，去除输出照片的元数据；不放大原本较小的图。

桌面树上保留 300 个拍立得实例，窄屏 220 个。照片少时重复分布，和原版多次使用同一张照片的方式一致。这是树上卡片数，不是要求准备的照片数。图集最多采样 256 张，超过时在整本相册中均匀抽取，完整相册仍然可以逐张查看。点击树上卡片会打开对应的原相册照片。

## 操作与分享

- 鼠标拖动或单指滑动旋转视角；滚轮或双指缩放。
- 点击树上的照片打开相册；相册支持左右按钮、方向键和手机左右滑动。
- “散开／聚合”同时改变照片、树叶与装饰的位置。
- “暂停”停止树的自动旋转；关闭页面或打开相册时停止后台渲染。
- 按系统“减少动态效果”设置关闭自动旋转，并直接切换聚合状态。
- “分享”提供当前页面的链接、二维码和可用时的系统分享面板。

收礼人只需点链接或识别二维码。二维码和静态托管不要求收礼人理解域名。当前保留现有网址；并未接入微信小程序。

## 发布

Vite 使用相对资源路径，支持根目录或子目录托管。生产构建只部署优化后的 WebP；`dist/photos/` 内的原图会移除，源码目录里的原图保持完整。

本分支的预览工作流只替换 `gh-pages` 的 `preview-2026/` 目录。原站根目录及其 `CNAME` 不受预览构建影响。工作流用 `GITHUB_TOKEN` 写入预览构建后，需要一次已授权的 GitHub Pages 发布触发；不能仅凭工作流写入成功就认定公开预览已经更新。

`npm run deploy` 则是整个站点部署命令，适用于确定正式发布时，不能拿来替代上述隔离预览步骤。

静态托管中的照片能通过公开网址访问；`noindex` 只是不让搜索引擎索引，不是访问控制。

## 实现与验证

- `src/scene/PhotoOrnaments.tsx`：一批实例化、双面可读的 3D 拍立得；渐进加载图集；稳定的卡片到照片索引。
- `src/scene/photo-layout.ts`：保留原版尺寸的圆锥与散开布局。
- `src/scene/TreeDetails.tsx`：绿色树叶点、实例化挂件、彩灯、金星；独立背景雪与星点。
- `src/scene/TreeScene.tsx`：相机、整树旋转、触摸／鼠标控制和局部辉光。
- `scripts/prepare-photos.mjs`：任意照片数量的构建处理。
- `docs/PERFORMANCE.md`：与原版的体积比较及验证边界。

构建、静态检查、照片流程与空间布局可以在当前环境验证。当前提供的浏览器禁用了 WebGL（`GL_VENDOR=Disabled`），原版与此分支均不能在该环境创建 3D 上下文。因此，不能把这里的检查写成真实 GPU 画面或帧率验收；实际 3D 观感和设备性能仍需在支持 WebGL 2 的手机／电脑浏览器中检查。
