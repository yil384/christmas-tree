# 圣诞树场景、材质与性能验证

本轮继续原版旋转照片树的 PR，修复树脚悬空、缩放范围过宽和拉远后雪花边缘空白的问题，同时增加针叶、树皮和拍立得的真实表面层次。首页仍只有场景与指定祝福，没有按钮或操作说明。相册照片数量与现有隐藏交互保持兼容。

最新调整加入童话城堡冬夜氛围，并处理顶星独立转动、强发光和粗糙边缘。远景城堡、前景照片树、雪地及灯光采用统一的蓝紫与香槟金配色。

## 树脚与相机

`GROUND_Y` 是树、雪地和雪花共用的世界坐标。树干最低点比雪地低 0.18 个单位，使树脚实际插入雪地。雪地有细微起伏、颗粒凹凸、树脚接触和树冠遮光；阴影是随聚散淡入淡出的程序化近似，不是实时阴影贴图。雪地远处使用同一张夜景的投影颜色衔接，避免雪地平面出现明显浅色边缘。

相机根据视口宽高和视场角计算完整树的最近距离；默认距离为其 1.08 倍，最远为 1.38 倍。限制俯仰角，避免进入地面下面。屏幕旋转或尺寸变化会保留相对缩放及观察方位。Safari 在画布上的原生缩放手势也使用同一组相机界限；页面其他面板保留正常浏览器行为。

## 材质与几何

- 树体仍为三批几何：树干与木枝、内冠与松枝、实体针叶。约 24,705 根有截面的针叶，总树体约 174,912 个三角形；缓冲区约 12.9 MB。没有按每根针叶增加绘制调用。
- 树皮有纵向纹理、裂纹和法线变化。针叶、树干与纸张共享方向光、环境光和暖色补光。取消树叶的自发光，聚合完成后不再叠加绿色发光点。
- 照片为桌面 128／窄屏 90 个实例。纸张有前后表面、厚度、微卷曲、纸边和照片区域的不同粗糙度；木夹有双夹片、弹簧，挂绳有截面。每个共享挂卡几何 342 个顶点／424 个三角形，仍共用一次实例化绘制。
- 顶星使用圆角轮廓、略鼓的正反面和平滑法线，保留与树梢连接的细支杆。取消顶星独立自转、摆动和上下浮动，恒定柔金自发光与较宽的金属高光减轻晃眼；顶星仍跟随整树慢转与聚散。缩小方盒和柱状挂件，保留照片、彩灯和挂件的整体结构。
- 灯串统一为暖香槟、金色与少量珍珠色，缩小明暗变化幅度。后处理主目标根据 HDR 颜色附件和深度附件的共同支持启用最多桌面 4 / 窄屏 2 个 MSAA 样本，并放宽泛光亮度过渡，减少细边和高光的跳变；未增加后处理分辨率。
- 辉光强度降低，使用 ACES 色调映射；光源发光，纸边与雪花保持清楚。

## 雪场和背景

雪花是独立的世界坐标粒子池，桌面 960／窄屏 480 粒，一批绘制。围绕当前相机视锥回收，保留真实远近和观察视差。边缘密度检查只在出现空缺时回收屏外或过密区域的粒子，避免拉远、旋转或改变宽高比后雪花集中在屏幕中央。近处雪花有柔和离焦，远处较小；取消六角图标形状与加法发光。粒子在地面上方淡出回收。

默认背景是本地 AI 生成的童话城堡冬夜：蓝紫暮色、暖金灯窗、远景薄雾和有纵深的雪庭。主城堡位于前景树旁，裁切焦点偏向主塔，手机竖屏也保留城堡的可识别部分；前景树、照片和雪地使用相应的冷暖照明。背景经构建脚本压缩为最长边不超过 1920 px 的 WebP。沿用 `public/scene.json` 的图片路径、亮度和裁切设置，可替换为自己的实拍照片。照片背景启用时关闭额外的程序化星点，夜景仍独立于树的旋转。

## 加载与构建体积

保留原图、缩略图与相册大图分层加载、有限图集和按需相册模块。可选手势模式采用独立延迟加载入口；普通打开页面不申请摄像头，也不下载识别模型。当前 32 张原始照片保持不变。最终产物不重复发布源照片和背景文件。

手势 SDK 固定为 `@mediapipe/tasks-vision@1.2.2`，版本 1 的模型为 8,373,440 B，构建时校验 SHA-256。生成的手势运行时、WASM、模型和说明合计约 22.40 MiB，只在用户点击开启后由当前站点提供。推理在独立经典 Worker 内以 CPU / WASM 执行；MediaPipe 的输入桥接仍需要 OffscreenCanvas / WebGL。普通页面没有这部分计算开销。

视频采用理想 640 × 480 前置摄像头约束，不请求音频。推理上限桌面 15 次 / 秒、触屏或窄屏 10 次 / 秒，按处理耗时降低频率；从创建 ImageBitmap 开始就只允许一个在途帧，不建立待处理队列。过期结果被丢弃，低帧率不会用未观察到的中间状态补出手势。退出、切后台、权限晚到、Worker 失败及视频轨结束均释放摄像头、定时器和 Worker。

手势光标通常约 15 次 / 秒检测真实照片实例；捏合请求在下一渲染帧按其锁定光标重新拾取，避免使用旧位置的命中结果。新星光效果单次为 96 个点、一次绘制、2.85 秒，闲置不绘制，减少动态效果时跳过。

精确文件字节统计见 [build-metrics.json](build-metrics.json)。这些是构建产物的文件体积和 gzip 体积，不是网络加载时间或设备帧率。新针叶与纸张增加了运行时几何细节；其性能需要在目标手机上测量。

## 验证范围

- 143 项自动检查通过。53 项场景基线覆盖照片处理与原图保留、实体树几何与法线、主干可见性、卡片不穿树冠、挂绳连接、隐藏交互排他逻辑、缩放边界及雪场分布；新增 37 项手势意图、25 项相机运行时 / Worker / 网络 / 模型，以及 28 项相机和真实纸面命中测试。
- 雪场测试包含 5 个视口、120 个相机组合：检查所有屏幕边缘都有雪花、近远深度、地面边界、固定粒子上限及减少动态效果。
- TypeScript、生产构建与 `git diff --check` 通过。
- 实际打开发布后的页面，验证 H 键与约 1 秒鼠标长按祝福语能进入手势图鉴，关闭后可再次打开；点击开启后，当前无摄像头环境正确显示“没有找到可用的摄像头”及重试入口，场景页面没有被错误替换。线上图鉴截图见 README。浏览器只读检查接口不暴露真实 `video.srcObject`，因此未把它用作相机关闭的端到端证据；资源释放由运行时竞态测试覆盖。
- 用 Three r169 的实际 `WebGLPrograms` / `WebGLProgram` 生成包含灯光、实例化和着色器片段的完整程序；在 EGL 1.5、Mesa GLES 3.2 llvmpipe 中验证 20 个程序／40 个阶段的编译与链接。包括新星光效果、实际线性合成路径及直接 ACES/sRGB 输出路径，编译和链接日志为空。结果摘要见 [shader-validation.json](shader-validation.json)。
- 使用真实树体几何、128 个实际挂卡位置、照片与夹子几何、背景、相机和雪地进行 Blender CPU 离线结构检查，发现并修复顶星悬空与部分挂件过大。离线光照和阴影与网页不同，它不是网页截图。
- 对新版城堡背景和圆角顶星完成一次 1040 × 650 离线构图检查；主城堡位于树旁，星体采用源几何及平滑法线。另按实际背景裁切算法检查 390 × 844 竖屏，主塔、尖顶和入口位于裁切范围内。该竖屏检查针对背景，不代表手机上树体遮挡和帧率已经验收。

这里的浏览器仍报告 `GL_VENDOR=Disabled`，无法创建 WebGL 上下文。已完成的编译、数学检查和离线结构渲染不能代替最终浏览器中的合成光效、照片指针命中、手机帧率及微信浏览器实机检查。预览继续发布在既有的 `preview-2026/` 路径。
