# 实体树、挂卡、夜景与隐藏交互

本轮在旋转的 3D 照片树上补足真实主干与枝叶，照片变成挂在树上的卡片。保留按需加载、相册与分享；首页撤掉全部按钮和操作提示，只显示左下角祝福。

## 树和照片的结构

实体树由棕色主干／枝条、连续绿色内冠与不规则松枝、针叶细节组成，共三批几何。即使照片数量为零，仍是一棵完整的树。

照片从密集遮住树体的外壳调整为桌面 128、窄屏 90 个实例。按树表面积分布，减少树冠处堆叠，保留绿色间隙、露出的主干与顶端。照片、木夹与细挂绳共用一个 InstancedMesh。挂绳向内连接连续树冠，照片四角则位于枝叶安全包络之外，避免下边缘穿进树体。

默认相机略降低；主干在最低枝叶下方露出 3.8 个局部单位。真实几何射线检查发现，旧的俯视角度会把露出段挡住，因此相机与主干长度一起调整。测试从 12 个方向检查可见主干，避免仅有“模型中存在树干”却看不见的回归。

树叶点作为实体枝叶的补充，桌面 6,800 点、窄屏 4,000 点。保留彩灯、挂件和金色立体顶星；整个树体、照片与灯饰共享旋转，聚散由阻尼和 GPU 片段变换完成。图片仍保留正反两面与正确方向。

## 夜景与雪

夜景读取本地 `public/scene.json` 配置，在构建时将选定图片生成最长边不超过 1920 px 的 WebP。默认星夜／松林背景只有 11,722 B。原图留在源码中，生产目录移除重复原图。图片按视口比例和可配置焦点裁切，不跟随树旋转。

雪位于独立空间层，桌面 480、窄屏 180 个点精灵。远处是较小柔和雪点，近处较大的雪花有六角轮廓和缓慢自转，尺寸、速度与漂移存在变化。减少动态效果时冻结，后台和面板打开时暂停整个场景渲染。

## 隐藏交互

首页没有按钮和操作说明。单击延迟约 330 ms 确认；双击仅触发聚散，不额外触发旋转开关。长按 650 ms 查看照片，空白处长按打开分享。拖动、双指、取消、失焦和后台都会取消候选操作。相机拖动的缓冲只用于真正的视角移动，普通单击继续旋转不会额外等待一秒。

- 测试覆盖照片／背景转换及原图保留、实际树体体积、向外法线、主干可见性、卡片不穿叶片、挂绳连接、聚散边界，以及单击／双击／拖动／双指／长按的相互排除。
