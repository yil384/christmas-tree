# 城堡巡游实测记录

日期：2026-11-09。

## 连续播放

使用实际网站组件、正式双档 HLS、正式终幕图片和正式 90 秒音轨进行浏览器验收。手机布局通过同源 iframe 提供真实的 440 × 850 CSS 视口，不冒充 iPhone 或微信真机。

一次点击金色钥匙后，不再点击页面或跳转进度，完整自动播放到结束：

- 影片按 `playbackRate=1` 运行，18 段实片剪辑的名义长度为 228.5 秒。
- Chrome / hls.js MSE 实测媒体末尾为 228.585 秒；AAC / MSE 尾部边界令浏览器读数比清单多约 0.085 秒。
- 影片 `ended` 后自动进入终幕，没有第二次播放手势。
- 终幕局部 18.71 秒时，真实 AAC 配乐位于约 18.65 秒，`data-sound=score`，未静音且正在播放。
- 终幕准确到局部 90 秒后结束，完整体验浏览器读数为 318.58 秒，即约 5 分 19 秒。音轨也随之暂停。
- 全程 `data-hls-error`、`data-fatal-error`、`data-media-error` 为空，网络和媒体恢复次数均为 0。
- 实际观看到水道、图书馆、花园及城堡终幕的不同画面；没有把静态背景缩放称作主影片运镜。

## 已发现并修复的问题

1. 当前 Chrome 声称支持原生 HLS，但直接加载清单在 0.59 秒中断。现改为 iOS / 真正 Safari 保留首击内的原生 HLS，其余具备 MSE 的 Chromium 优先 hls.js。修复后才完成上述整段自动实播。原生解码 / 不支持错误也有一次有界 MSE 回退。
2. 主片时长带小数时，暂停后跳到总末尾可能得到 `89.99999999999997` 秒，界面仍为暂停。现把距终幕末尾不超过 1e-6 秒的时间规范化为 90 秒。用实际 228.585 秒时长现场复测后，末尾立即显示重播按钮，并成功从影片 0 秒重新开始。
3. 音轨真实缓冲时允许合成氛围短暂接管；主动暂停或切回影片导致的正常 AbortError 不会把真实配乐永久标记为失败。

## 控制与布局

- 影片 / 终幕边界的双向十五秒跳转，实际播放通过。
- 暂停在终幕局部 17.50 秒，切换 440 × 956 与 390 × 760 视口后仍严格保持 17.50 秒，音轨同步暂停。
- 静音按钮实际令音频元素 `muted=true`，恢复声音后继续可用。
- 390 × 760 布局中的声音、回看、播放、前进按钮均为 46 × 46 CSS 像素，全部位于屏内。
- 结束后的点击烟花没有重启主线或配乐。
- 整段重播从影片开头开始，并继续播放。
- 实际点击了“吊灯下的小光灯”热点，发现状态更新为已发现，影片继续前进，没有被彩蛋重置或暂停。
- 主巡游不插入字幕卡或生成的人物主角；告白入口与巡游结束后的明确表白，见下面的补充记录。

## 终幕渲染的验证边界

本次 Cloud Chrome 的 `canvas.getContext('webgl2')` 返回 null。没有改变浏览器安全设置，也没有将 Canvas 截图说成真实 GPU 截图。

Three.js 版本通过 TypeScript、完整 90 秒状态更新、矩阵有限性、固定实例容量、暂停和 seek 的检查。实际浏览器中验证的是完整 Canvas 兼容版本：已查看 27 秒纸灯笼、45 秒蝶翼 / 花瓣、54 秒蝶形星座、76.8 与 81 秒烟花。背景保持固定，灯笼具有可辨认的灯罩、肋线、灯芯与前后大小，水面反射限定于原图湖面。

Canvas 兼容版与 Three.js 版使用相同演出时间表；兼容版不是每几秒出现一小团通用亮点。其状态与绘制调用测试包括完整 2701 帧、减少动态 901 帧、逆序 seek、暂停互动冻结和 1000 次连续点击，有固定容量上限。

尚未进行 iPhone 微信真机测试；原生 Safari HLS、真实移动设备 GPU 和宿主媒体权限仍属于真机验证范围。

首个完整发布包因解包体积超过 256 MiB 被拒绝，未部署。随后仅在构建收尾中排除了已经脱离当前入口的 `dist/princess/` 和无引用的 `dist/hd-assets/`，合计减少 14,038,208 字节；其源码素材仍保留在 Git。当前巡游与圣诞页均不引用这两个旧素材目录，正式影片、照片及手势功能不作压缩删减。

## 正式域名音轨兼容修正

第 23 版在线检查确认主影片自动进入终幕、正式配乐自动播放，但线上 M4A 的 `seekable` 为 `[0,0]`，导致终幕跳转后配乐被反复拉回开头。音频现于影片最后 20 秒（或提前进入终幕时）完整下载一次，明确为 `audio/mp4` 的 Blob 绑定到首击已经解锁的同一个音频元素。回看、快进与重播复用这份缓存，卸载时中止未完成请求并释放 URL；请求失败时保留合成配乐。该修正不提前加载到首屏，也不修改镜头或终幕时间线。
