## 故事

男主准备了很隆重的城堡晚宴，却一直忙着安排，没坐到思仪身边。她从自然的小猫互动、被郑重端上的榴莲和那本尚未完成的双人旅行册里，认出他记得两个人想去马来西亚的愿望。两人把正式舞会改成一起出发的奇幻预演。最后电影接到真实网页，明确说出表白，把回答留给她本人。

故事里的马来西亚是**未来共同愿望**。没有编造已经去过的旅行、预订、日期或恋爱答应。她不需要解题，也不用点击才能看到完整故事。

## 开始制作的顺序

1. 在 [现有 Google Vids 工程](https://docs.google.com/videos/d/1xqNPZ0ASqpQNVnWTWnn6-8Jmwpuc7lrp5TaCzxB7_zU/edit?scene=id.p#scene=id.p) 中确认使用用户指定的创作账号。没有登录时先保留制作包，不把成片状态改为完成。
2. 先做 **S02 人猫互动**和 **S06B 面部反应**，检查真人脸是否接近原照、猫是否正常、动作是否自然。若两条均不能达到要求，先修正，不批量生成整片。
3. 每次使用原始真人照片作为身份参考：`../film/HUMAN_ORIGINAL.jpg`。再添加该镜头列出的场景图；出现猫时添加 `CAT_IDENTITY.png`。不可把新生成的人脸作为后续身份替代。
4. 对相邻连续动作，尝试平台实际的 **Extend** 按钮。只在当前真实可用的会话和片段上操作。具体可用时长、分辨率及可重复延长次数以实际 UI 为准，不做未经验证的承诺。
5. 若 Extend 不可用，使用完整的 29 镜头剪辑方案，每次换成明确不同机位。它不是同机位重复 Create 假装续拍。
6. 下载实际素材后，填写源文件、原始时长、批准剪入的起止秒数。322 秒现在是计划；最终时间轴必须由真实素材实测生成。
7. 最后统一声音、调色和中文字。电影不生成中文按钮；艺术字、表白和真实回答控件由网页排版。

## 实施边界

这是一部需要真人表演、自然猫动作与真实剪辑的短片。静帧、相机慢推、定格、被放慢的镜头、重复片段、加载等待和片尾停留均不能补足五分钟。至少有 300 秒合格的实际剧情素材后，才可称为满足五分钟要求。

人物的一致性必须逐条验收；参考图和提示词不能保证模型输出完全同一张脸。男主在没有本人合适参考影像前只拍手、肩背与被裁掉面部的构图。台词若使用演员或合成配音，不称作用户原声。

结尾必须保留两层表达：

> 谭陈思仪，我喜欢你。要不要和我在一起？
>
> 马来西亚那趟，我想和你一起去。

页面的“好呀 / 先不了”是她自己选择的真实回应，不由影片或彩蛋预先代答。
