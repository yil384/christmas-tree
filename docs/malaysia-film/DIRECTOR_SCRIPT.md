一、创作依据与单句核心

用户确认的真实信息只有：思仪喜欢小猫、爱吃榴莲、害怕鸡鸟等尖嘴动物；她想与用户一起去马来西亚，这趟尚未实现的旅行是两人之间的私人愿望。

故事核心：男主为思仪准备了一场美得像童话的城堡之夜，却始终把自己放在布景外；当她从小猫、榴莲和那份马来西亚旅行准备里认出他的认真，他终于走到她身边，两个人把舞会改成出发，而真正的表白留到电影与手机页面相接的那一刻，由他亲口说出来。

可见的行动目标：结束独自表演式的接待，把小船从码头转向现有的海湾拱洞，并且让男主也登船。拱洞在场景母版中本来就是敞开的，不新增机械水门。
人物变化：他开始时忙着让一切按排练完美运行，自己却像工作人员；结尾他愿意打乱排练，与她站在同一边，明确说出喜欢。
思仪的行动：她亲近猫、认出自己喜欢的食物与两人谈过的旅行、给男主留一个座位、与他一起调整出发空间。她不替男主完成表白，也没有被写成已答应恋爱。

两次中段变化：
1. 男主第一次试图按排练开口，舞会音乐提前响起；他又退到帘幕后。桌边空椅与码头小船上空着的第二个座位形成呼应。这让“安排过分隆重、自己始终缺席”的问题变得可见。
2. 准备间暴露了真实的私人准备：榴莲、两把勺子、马来西亚的双人旅行速写。女主将第二把椅子放到身旁，男主才决定停掉自动舞会，亲自和她把空间改成出发平台。第二次面对一直等在码头的小船，他不再重置排练，而是与她配合安放行李、稳住船头，最终一起出发。

全片不是收集道具、解三道谜、救动物或经历危险。城堡是被认真准备的一份礼物，始终保留它的华丽、温柔与公主感。改道是让这个世界更贴合思仪，绝非反公主或逃离城堡。

二、角色和美术锁定

S / 思仪：每次生成人物都直接引用 docs/film/HUMAN_ORIGINAL.jpg。原照是身份唯一主基准：浅蓝花瓣礼服、棕色刘海半扎、耳坠和项链。保持原照的眼鼻口、脸型、肤色和比例；不把场景图里新生成的脸当作新的身份依据。动作自然克制，眼神与呼吸、轻笑、坐下、俯身、抬手和走路是主要表演。不安排高速转头、夸张大笑、双人杂技或吻戏。

Y / 男主：在获得用户本人合适影像前，只使用象牙白长袖衬衣、深海军蓝长裤、手、肩背或裁去面部的构图；实际场景母版里的深蓝外套始终留在准备间椅上。不生成一张陌生男人的正脸来冒充用户。可有很轻的笨拙：扶正杯子、抢拍子、发现自己又站到帘幕后；不摔跤、不装傻、不嘲笑榴莲。男性声音若采用合成旁白，属于影片角色配音，不宣称用户原声。用户原声可替换全部角色告白台词。

C / 小猫：以 docs/malaysia-film/references/CAT_IDENTITY.png 为固定外形参照的一只自然比例灰白短毛猫，圆润脸型、短而正常的鼻口、普通大小的眼睛、柔软短耳与自然尾巴。四足、正确关节、真实猫步。活动只在城堡左窗台至小圆桌附近；最多慢走、伸懒腰、嗅闻、蹭腿、眨眼、蜷卧。小猫不说话、不指路、不持物、不当钥匙、不跳到人脸旁、不吃榴莲、不参与危险。全片约 30–40 秒有猫，避免把它变成第二主角。

A / 城堡主厅：三面有宽拱洞的象牙石舞厅，香槟金细节，午夜蓝外景与暖烛光。左侧宽拱窗、低窗台固定；中后景精致小圆桌与两把椅子；右侧一扇拱门通准备间 B；后方窄运河与码头，双人小船船头初始朝画面右侧。后方既有敞开拱洞通向海湾，不新增门扇、手柄或机械机关。前段小船始终系在同一码头、同一位置，只随水面轻微起伏；没有自动出发、环游或返回。直到 B16 才由男主解开系绳。音乐盒在右拱门旁矮台上，系船绳在码头右侧圆头系船柱上；这些小道具必须在首批有效素材中建立并固定。合上音乐盒盖只让舞会乐声收住，不控制运河或船。

B / 准备间：A 的右拱门后。后墙工作台、右侧小圆窗望同一运河、左侧门洞看回 A。实际 B 母版表现的是盘子到达后的状态；入门镜头开始时桌上的同一位置应为空，待思仪放下唯一的盘子。到达后固定道具：盘内三瓣金黄榴莲果肉、两把小勺、椅上的深蓝男外套、地面打开的空行李箱。可用一本未完成的双人旅行速写册承担未来愿望线索；任何新增小船模型或银罩都必须先在实际连续性素材中建立，不能凭空每镜出现。这里仍是漂亮、温暖的城堡一部分；不做破败后台、杂乱工具房或黑暗密室。没有订票确认、具体航班、酒店订单或虚构已经旅行的照片。

C / 出发平台：同一个 A，桌椅被移到左后方，帘幕收在两侧，既有外侧拱洞始终敞开，小船来到近处。建筑空间不重生：保留左窗、右拱门、石地与原有码头位置。

D / 马来西亚未来预演：从 C 的既有运河拱洞连续进入的温暖海湾。小规模彩色骑楼、榴莲摊、热带树影、海岛和海风构成未来旅行的画面。它是一段想象中的共同出行，不声称两人已去过某城，不拼贴全国地标，不杜撰具体预订。可以抽象呈现马来西亚海边与街道，不强行宣称这是某个真实景点。

色彩：A/B/C 为象牙白、香槟金、夜蓝、浅蓝礼服；D 保留浅蓝与暖金，增加少量热带绿色。通过拱洞时发生一次明确的魔法光线转变。无突如其来的白昼、换装或换季。

绝对排除：鸡、鸟、海鸥、鹦鹉、猫头鹰、鸭鹅、尖嘴动物、鸟形屋脊、羽翼纹样、鸟笼、纸鸟、飞鸟剪影、鸟叫、动物鸣唱。灯饰与雕刻使用花叶、水纹、贝壳、圆月、几何曲线。也不加入蝴蝶等飞行动物，以免自动生成时混入鸟类轮廓。

四、生成与剪辑安排

1. 生成素材与成片时间分开记录
本稿 B01–B22 是剧情段落，并不等同于“22 次生成”。段落长度可超过一次 Create 的原始素材上限。用真实可用片段剪出 322 秒，不用拉慢、定格、无动作循环或互动等待凑满五分钟。

2. 优先真实 Extend 的连续组
E1：B05→B06，猫经过桌边至揭开银罩，计划成片 28 秒。固定 A，保持盘子/猫/裙摆/桌椅关系。
E2：B14→B15，移动桌椅至两人打开帘幕，计划成片 31 秒。固定 A→C，同一相机位置与建筑，不改装潢。
E3：B18→B19，通过既有拱洞到达未来海湾，计划成片 29 秒。固定同一小船、衣服、镜头高度与航向，色温变化只发生在清楚的门槛处。
E4：B21→B22 的影片底层海湾镜头，计划成片 30 秒。画面继续自然运动；网页框与中文字后期合成。

Extend 只用于当前会话里实际生成的上一条片段，必须操作平台真正的 Extend。根据平台实际返回的时长决定是否再次 Extend；不要假设每次固定增加 15 秒。长镜头若已经自然成立，应保留需要的真实长度，不机械裁成 15 秒。

3. Extend 不可用时的合法改法
不是把相同提示词再 Create 一条当“续拍”。改成明确不同机位：猫腿边切手揭罩、推桌全景切帘幕扣近景、船尾背影切船头/岸边、烟花全景切海面倒影。每个新镜头仍加载该场景母版、身份原照、上一个镜头的服装与道具约束。

4. 基础素材预算
若全部按明确剪辑镜头生成，22 个剧情段落中 7 个超过 15 秒，至少拆成 29 个 Create 素材；每个原素材按平台可用设置通常取 15 秒，预留剪辑余量。采用 Extend 后不预先承诺调用次数：以实际长度与质量为准，记录每条素材归属、原始时长、可用区间及末帧状态。

5. 不在每条 prompt 堆入所有剧情
每次只说明当前机位、一个连续主要动作、人物位置、起止状态与禁止项。短镜头一般只承担一个动作加一个反应。对话镜头最多一句，复杂口型与脸一致冲突时优先自然动作，并将告白作为外部旁白配在稳定镜头上。

6. 声音
主配乐由同一三音动机贯穿：入场轻柔、自动舞会稍隆重且一次抢拍、准备间缩小为拨弦或钢琴、改道渐渐加回弦乐、海湾开放、告白降低音乐给人声让位。
环境音分 A/B/C/D 四层，保持同一运河水声连续；猫只有轻呼噜和爪垫声，不使用拟人声音；D 不用鸟叫。
若只有一段音乐，按这些转折做自然剪辑与音量自动化，不把不同风格的曲子直接拼在一起。
